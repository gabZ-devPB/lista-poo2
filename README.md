# 1. Getters e Setters

Getters e setters são uma boa prática porque mantêm os atributos privados e permitem controlar o acesso e a alteração dos dados. Por exemplo, um setter pode impedir que o preço de um produto receba um valor negativo, mantendo a integridade dos dados.

# 2. Sistema de Biblioteca

### a. Informações relevantes de um livro:

* ISBN
* Título
* Autor
* Editora
* Ano de publicação
* Gênero

### b. Abstração:

A classe `Livro` é uma abstração porque representa no código as principais características e comportamentos de um livro real que são importantes para o sistema.

### c. Métodos:

* `emprestar()`
* `devolver()`
* `exibirInfo()`
